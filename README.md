## What I'm building: [SubMob](https://submob.app)

SubMob helps recreational and intramural sports teams find substitute players, so games get played instead of forfeited. A captain who's short a player posts a request, nearby players get an alert, and the captain accepts a sub.

- **Stage:** live at submob.app (invite-only), working toward a pilot with Texas A&M Intramural Sports
- **Stack:** React Native (Expo, TypeScript) for web, Android, and iPhone from one codebase, on Firebase (Authentication, Firestore, Cloud Functions)
- **Quality:** 155 automated tests against local Firebase emulators, plus a headless-browser smoke test that blocks any failed deploy
- **How it's built:** I own the product decisions, design, specs, testing, and deployment, and direct Claude Code (an AI coding agent) on implementation

The code is in a private repository. I'm happy to walk through it on request.
